# S31 data and reuse

The exact source is the archived **CASdatasets 1.2-0** ZIP in *Insurance dataset*, Dutang, Christophe; Charpentier, Arthur; Gallic, Ewen, Recherche Data Gouv, [doi:10.57745/P0KHAG](https://doi.org/10.57745/P0KHAG), dataset version 1.1 released July 12, 2024. File DOI [10.57745/ULR0ZA](https://doi.org/10.57745/ULR0ZA), unrestricted file ID 222040. `config.json` pins archive and extracted R-file hashes. The 209,762,233-byte archive also matches the publisher MD5. Retrieval uses verified HTTPS and a 220 MB limit; no authentication bypass.

The dataset metadata assigns [Etalab Open Licence 2.0](https://spdx.org/licenses/etalab-2.0.html). The package DESCRIPTION separately licenses package code under GPL >=2. This study reads data and publishes original analysis plus aggregates; it does not copy package code or redistribute policy records. Attribution, source date and transformations are retained. No publisher endorsement is implied.

The [publisher dictionary](https://dutangc.github.io/CASdatasets/reference/freMTPL.html) identifies an unknown private French motor third-party liability insurer and an approximate 2011–2013 period. There are no reliable individual dates. The documented 11-column count differs from the actual 12 frequency columns (the publisher example agrees with 12). Data are nominal historical euros, exposure in years, ages in years and density in inhabitants/km². Some claim amounts reflect French IRSA/IDA settlement conventions rather than unconstrained economic loss.

Actual archived files contain 677,991 unique policy IDs, 26,444 claims on 24,944 policies, no missing fields, strictly positive exposures/claim amounts and no unmatched severity IDs. After aggregating severity **by the textual ID**, every policy's number of severity rows equals ClaimNb. R factor codes must never be used as join keys. The 235 identical severity rows are retained: equal compensation amounts can represent distinct claims, and removing them breaks the count identity. No frequency rows are duplicated. There are 1,224 exposures above one year (maximum 2.01); actual exposure is retained. Total exposure is 358,482.835463 policy-years and total nominal loss €59,909,216.50. The largest claim is €4,075,401.

Risk fields are Area, VehPower, VehAge, DrivAge, BonusMalus, VehBrand, VehGas, Density and Region (historical French region names). Claims and loss are outcomes; Exposure is a denominator/weight, not a feature. IDs only join and allocate splits. This retrospective benchmark assumes risk fields were available before claims; absent field-level timestamps and claim-development dates prevent verification of prospective underwriting or ultimate-loss performance.

Raw data, parsed caches, policy predictions and source audits remain outside Git and the website. Ingestion rechecks the pinned source before reconstructing the join; no external cache is accepted as research evidence without the source verification.
